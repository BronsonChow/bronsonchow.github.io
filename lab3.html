1. Type : Hall v Mechanical

The two types of keyboards that will be the topic of this page will be the traditional mechanical and Hall Effect. Hall Effect (HE) keyboards are generally more durable and reliable due to the fewer points of contact/friction. Effectively though, durability is a non-issue when it comes to either one of these two options. The difference lies in the analog switches in Hall Effect keyboards. Rapid trigger allows for near instant re-actuation of switches and you are also able to set the actuation point per-key. Otherwise, generally more companies offer more customization options for traditional mechanical keyboards.

2. Size : The Dealbreaker

Nearly all custom HE/mechanical keyboards are per key programmable. The sections display the default configuration.

Section Color Convention:

Section Name Color
Alphabet Keys Red
Numeric Key Orange
Misc. Alphanumerics Yellow
Navigation Keys Cyan
Arrow Keys Sky Blue
Function Row Blue
Number Pad Dark Blue

    100% +

  • The universal standard
  • Anything bigger just adds macro keys
  • Possible alternatives include volume knob
  • Sections:
    • Alphanumerics
    • Function row
    • Navigation pad
    • Arrow pad
    • Numpad

    95%

  • A bit more compact
  • Usually for those who never use the full control pad, but they swear by the numpad
  • Right side control row keycaps typically resized to normal width
  • Sections:
    • Alphanumerics
    • Function row
    • Navigation row
    • Arrow pad
    • Numpad

    80%

  • If you think trading the numpad for space is a good deal
  • Sometimes seen with 1 less column of navigation pad keys on the right
  • Sections:
    • Alphanumerics
    • Function row
    • Navigation pad
    • Arrow pad

    75%

  • Noticeably less rectangular
  • If you think that even 80% has too many navigation keys
  • Most likely reprogrammed into macro keys
  • Sections:
    • Alphanumerics
    • Function row
    • Navigation column
    • Arrow pad

    65%

  • Now we enter the territory of exercising the function key
  • The major update being the lack of a function row
  • If you dislike repositioning your hand to reach for macros/nagivation keys
  • More efficient than larger sizes if you don't mind utilizing the function key
  • Sections:
    • Nearly all alphanumerics
    • Navigation column
    • Arrow pad

    60%

  • The free thinker's keyboard
  • You have no need for the arrow pad because the thought occured to you: Why do I have an arrow pad when I can just remap the wasd keys?
  • Near maximum efficiency; there is barely a need to lift your wrists
  • Sections:
    • Nearly all alphanumerics

    50%

  • The largest length/width ratio
  • Why stop at the arrow pad? Let's just remove the number row because we can just remap that
  • Some alphanumerics were harmed in the making of this keyboard
  • A couple navigation/macro keys typically on the left side
  • The key layout varies a lot by this point
  • Sections:
    • All of the alphabet remain
    • Some miscellaneous alphanumeric keys

    40%

  • The "final" frontier
  • Anything other than the alphabet is near useless to you
  • You use the function key more than the alphabet
  • Sometimes seen with a perfect grid layout
  • Not unusual to have a split spacebar either
  • Sections:
    • All of the alphabet remain
    • Few miscellaneous alphanumeric keys
